# Alarmclock_Mk2
Second prototype of my adhan- and alarmclock

## What is the Alarmclock_Mk2?
The Alarmclock_Mk2 is the second prototype of a self-designed alarmclock, which shows the time and date, the next prayertime, and plays the Adhan and a alarm, if the time has come.

I used an ESP32 as the microcontroller, a MAX98357A as the amplifier, a 1.3" OLED, a SD-module and a rotary-encoder for input.

Available are code and pcb-files made in KiCad, available to use via MIT License. 

There are still some flaws, for example bouncing of the rotary-encoder, which are intended to be adressed in Mk3, which will be started soon.

I would be glad about feedback and criticism.
